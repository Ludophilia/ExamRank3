# Permutations

## Subject

- Create a program that displays every possible combination of a character 
string comprised of letters from the alphabet in the alphabetical order:

`./permutations "a"`
a

`./permutations "abc"`
abc
acb
bac
bca
cab
cba

## Notes

- if no arguments are passed to the program, `1` should be returned to the user.
